# Four-run baseline WPR comparison

The original first baseline plus all three 17 September repeats use the same CSX DLL and gameft-sw protocol. Every table uses the saved world-entry +[50,60) seconds. The three fresh repeats match each other in before/after feature settings; the original has other settings differences listed in [comparison.json](comparison.json). All four have active FOV+TAA centre 0.30 / outer 0.70. The saved FOV-only value is inactive.

Parentheses show each repeat minus the original. The median and range describe the three fresh repeats of the same save, not independent scenes or a significance test. DLAA: 08/09/10; DLSS: 11/12/13.

fpsVR CPU latency, scheduled CPU execution, ready delay and blocked waiting are different measurements. A ten-second window can contain different numbers of recorded frames; both per-frame and fixed-window scheduler percentages are retained. Inclusive stack categories overlap and must not be summed. Zero matching samples does not prove zero cost. These CPU traces do not measure individual GPU passes.
