Spike threshold is each tail median +2 ms. All episodes includes single-frame spikes. Multi-frame groups count saved contiguous groups with at least two samples; this does not change spike detection. Duty is a sample percentage, not elapsed time. A raised tail median can hide sustained slow plateaus from spike counts; use absolute mean/P95/P99 alongside them.
