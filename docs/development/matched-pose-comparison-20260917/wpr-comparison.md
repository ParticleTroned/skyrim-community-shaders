# WPR: three baseline versus three head repeats

Every value uses the saved final [50,60) seconds of each hold. Head minus baseline medians. Three repeats per save; saves are different workloads and are not pooled. fpsVR CPU latency is distinct from CPU execution, runnable-but-not-scheduled delay, and blocked wait. Per-frame values divide by actual recorded tail frames; fixed-window percentages are also provided because cadence differs.

Sampled categories describe execution observed in call stacks. Inclusive contexts overlap and must not be summed or called exclusive hook cost. The material union counts each matching sample once. Zero sampled weight does not prove zero cost, especially for inlined functions. CPU stacks cannot time individual GPU passes. Native RVAs reuse the prior live snapshot mapping; 4 KiB pages are not identified functions.

Scheduler values marked \* exceeded the unchanged +/-5 ms accounting tolerance for a ten-second window. They remain provisional, are not renormalized and have no new acceptance exception.
